Simple setup checklist

1 · Create your webhookIn Make, create a scenario and add Webhooks → Custom webhook. Copy the HTTPS URL it gives you.
2 · Paste it belowScroll to Optional webhook, paste the URL, choose the report type, and add a recipient if you want email.
3 · Test safelyStart the scenario in Make, then click “Send now” in myTIME. Use sample punches first and confirm the run appears in Make.
One important limitation

myTIME currently saves punch data in this browser. A scheduled Friday report cannot read this browser automatically while it is closed. To automate reports, send the data to Make or a secure backend first and configure the schedule there.
